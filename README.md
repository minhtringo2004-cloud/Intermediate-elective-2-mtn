# Intermediate-elective-2-mtn
Intermediate Elective 2 193DD UCSB 2026

## General information

This repository contains data and code to explore patterns in aquatic invertebrate abundance at North Campus Open Space.

To work with the code in this repository, you will need the following packages:

```
library(tidyverse)
library(here)
library(janitor)
library(snakecase)
library(scales)
library(readxl)
library(showtext)
library(camcorder)
library(ggtext)
library(glue)
library(ggfx)
```
